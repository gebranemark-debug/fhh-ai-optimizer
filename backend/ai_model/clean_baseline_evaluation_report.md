## Interpretation

Recall is **1.000** — ✅ meets the 0.85 target. In production terms, that means the model would catch 100% of failures within their 72-hour warning window. Each missed failure is worth ~$20K/hour of unplanned downtime, so recall is the metric that matters most for predictive maintenance.

Precision is **0.977** — ✅ meets the 0.70 target. At this precision, roughly 2% of flagged hours would be false alarms; each one costs ~$5K in inspection time, so the ratio of recall (catches) to precision (false alarms) directly determines whether the system saves more than it costs.

ROC-AUC of **1.000** measures threshold-independent ranking quality. Above 0.90 is strong; in the 0.80-0.90 band there's still room to tune the threshold against the cost ratio above. F1 sits at 0.989.

**Caveat — synthetic data sets an upper bound on these numbers.** The training set was generated by a deterministic simulator with explicit failure precursor patterns; real Valmet failure data would be noisier and more varied, with edge cases the simulator doesn't represent. Expect the production numbers to land below these — possibly substantially below — until the model is retrained on real DCS history and labelled events.
